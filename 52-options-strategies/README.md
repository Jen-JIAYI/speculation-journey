## 🧠 核心策略体系

### 四大策略类别

#### 1. 方向获利方式（23种）
| 看涨策略（1-12）| 看跌策略（13-23）|
|-----------------|-----------------|
| 买入虚值/实值认购 | 买入虚值/实值认沽 |
| 卖出虚值/实值认沽 | 卖出虚值/实值认购 |
| 牛市价差（认购/认沽）| 熊市价差（认沽/认购）|
| 合成股票多头 | 合成股票空头 |
| 看涨保险/备兑/领口 | 看跌保险/备兑 |
| 反向比率价差 | 反向比率价差 |
| 旭日零成本策略 | 旭日零成本策略 |

#### 2. 时间价值获利方式（4种）
- 正向/反向日历价差
- 正向/反向对角线价差

#### 3. 隐含波动率获利方式（11种）
| 做多波动率（28-34）| 做空波动率（35-43）|
|-------------------|-------------------|
| 跨式/宽跨式 | 卖出跨式/宽跨式 |
| 条式期权 | 三腿/四腿跨式 |
| 蝶式期权 | 比率价差 |

#### 4. 低风险套利获利方式（9种）
- 不合理价格套利
- 转换/逆转换套利
- 盒式套利
- 平价套利
- 负时间价值套利
- 到期日套利
- 合并行权套利
- 跨品种套利
