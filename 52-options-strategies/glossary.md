# 期权术语表

## 基础概念

| 术语 | 英文 | 说明 |
|------|------|------|
| **认购期权** | Call Option | 买方有权在约定时间以约定价格买入标的资产的期权 |
| **认沽期权** | Put Option | 买方有权在约定时间以约定价格卖出标的资产的期权 |
| **行权价** | Strike Price | 期权合约约定的买入/卖出价格 |
| **权利金** | Premium | 期权买方支付给卖方的费用 |
| **到期日** | Expiration Date | 期权合约的失效日期 |
| **实值** | In the Money (ITM) | 有内在价值的期权状态 |
| **平值** | At the Money (ATM) | 行权价等于标的价格的期权状态 |
| **虚值** | Out of the Money (OTM) | 无内在价值的期权状态 |

## 价值相关

| 术语 | 英文 | 说明 |
|------|------|------|
| **内在价值** | Intrinsic Value | 期权当前具有的实值部分价值 |
| **时间价值** | Time Value | 期权价格中除内在价值外的部分 |
| **隐含波动率** | Implied Volatility (IV) | 市场对未来波动率的预期 |
| **历史波动率** | Historical Volatility | 标的历史价格波动的统计指标 |
| **波动率微笑** | Volatility Smile | 不同行权价期权隐含波动率形成的曲线 |

## 交易术语

| 术语 | 英文 | 说明 |
|------|------|------|
| **开仓** | Open Position | 建立新的期权头寸 |
| **平仓** | Close Position | 结束已有的期权头寸 |
| **买入开仓** | Buy to Open | 作为期权买方建立新头寸 |
| **卖出开仓** | Sell to Open | 作为期权卖方建立新头寸 |
| **买入平仓** | Buy to Close | 平仓原有的空头头寸 |
| **卖出平仓** | Sell to Close | 平仓原有的多头头寸 |
| **移仓** | Roll | 将期权头寸从当前合约移到其他合约 |
| **行权** | Exercise | 期权买方执行期权权利 |
| **弃权** | Abandon | 期权买方放弃行权权利 |

## 策略相关

| 术语 | 英文 | 说明 |
|------|------|------|
| **备兑开仓** | Covered Call | 持有标的的同时卖出认购期权 |
| **保护性认沽** | Protective Put | 持有标的的同时买入认沽期权 |
| **价差策略** | Spread Strategy | 同时买卖不同期权的策略 |
| **跨式** | Straddle | 同行权价同到期日的认购+认沽 |
| **宽跨式** | Strangle | 不同行权价的认购+认沽 |
| **蝶式** | Butterfly | 三腿价差策略，风险有限 |
| **铁鹰** | Iron Condor | 牛市价差+熊市价差组合 |
| **日历价差** | Calendar Spread | 不同到期日期权的价差 |
| **对角线价差** | Diagonal Spread | 不同行权价和到期日的价差 |
| **比率价差** | Ratio Spread | 买卖数量不同的价差 |
| **合成多头** | Synthetic Long | 买入认购+卖出认沽=合成买入标的 |
| **合成空头** | Synthetic Short | 卖出认购+买入认沽=合成卖出标的 |

## 风险指标

| 术语 | 英文 | 说明 |
|------|------|------|
| **Delta (Δ)** | Delta | 标的价格变化1单位，期权价格变化量 |
| **Gamma (Γ)** | Gamma | 标的价格变化1单位，Delta变化量 |
| **Theta (Θ)** | Theta | 时间流逝1天，期权价格变化量 |
| **Vega (ν)** | Vega | 隐含波动率变化1%，期权价格变化量 |
| **Rho (ρ)** | Rho | 利率变化1%，期权价格变化量 |

## 市场术语

| 术语 | 英文 | 说明 |
|------|------|------|
| **上证50ETF** | SSE 50 ETF | 上证50交易型开放式指数基金 |
| **沪深300ETF** | CSI 300 ETF | 沪深300交易型开放式指数基金 |
| **当月合约** | Front Month | 距离到期最近的合约 |
| **次月合约** | Second Month | 当月之后的下一月份合约 |
| **主力合约** | Main Contract | 成交量最大的合约 |
| **末日轮** | Option Wheels | 到期日当天的交易机会 |

## 套利相关

| 术语 | 英文 | 说明 |
|------|------|------|
| **转换套利** | Conversion Arbitrage | 买入标的+买入认沽+卖出认购 |
| **逆转换套利** | Reverse Conversion | 卖出标的+卖出认沽+买入认购 |
| **盒式套利** | Box Arbitrage | 牛市价差+熊市价差组合 |
| **平价关系** | Put-Call Parity | 认购认沽价格的理论关系 |
| **无风险套利** | Risk-Free Arbitrage | 确定收益的套利机会 |
