## 策略选择决策树

### 根据市场观点选择

```
你的市场观点是什么？

├─ 看涨
│  ├─ 小涨 → 认购牛市价差(5) / 认沽牛市价差(6) / 备兑开仓(9)
│  ├─ 大涨 → 买入实值认购(2) / 合成多头(7)
│  └─ 暴涨 → 反向比率价差(11) / 旭日零成本(12)
│
├─ 看跌
│  ├─ 小跌 → 认沽熊市价差(17) / 认购熊市价差(18)
│  ├─ 大跌 → 买入实值认沽(14) / 合成空头(19)
│  └─ 暴跌 → 认沽反向比率价差(22) / 看跌旭日零成本(23)
│
├─ 震荡
│  ├─ 赚时间价值 → 卖出跨式(35) / 卖出宽跨式(36) / 铁鹰
│  └─ 期限结构 → 正向日历价差(24) / 正向对角线(26)
│
└─ 方向不确定但有大波动
   └─ 买入跨式(28) / 买入宽跨式(29)
```

### 根据风险承受能力选择

```
你的风险偏好是什么？

├─ 保守
│  ├─ 最大收益有限、最大亏损有限
│  │  → 牛市价差 / 熊市价差 / 领口策略 / 蝶式
│  └─ 需要保险
│     └─ 保护性认沽 / 领口策略
│
├─ 平衡
│  └─ 愿意承担一定风险换取更高收益
│     → 备兑开仓 / 日历价差 / 对角线价差
│
└─ 激进
   └─ 追求高收益，能承受较大亏损
      → 买入期权 / 跨式 / 宽跨式 / 比率价差
```

## 作者独创策略说明

### 看涨/看跌旭日零成本策略 (12/23)

**特点**：通过巧妙组合实现零成本押注大涨/大跌

**优势**：
- 如果判断错误，没有亏损（零成本）
- 如果判断正确，收益无限

**适用场景**：
- 预期市场将出现暴涨/暴跌
- 有明确的方向观点但不想承担判断错误的成本

### 负时间价值套利策略 (49)

**特点**：利用深度实值期权时间价值为负的特性

**原理**：
- 深度实值期权的价格可能低于内在价值
- 买入并持有到期，可锁定无风险收益

### 到期日套利策略 (50)

**特点**：利用期权到期日当天的价格异常

**机会**：
- 到期日最后时刻，期权价格可能出现偏离
- 快速进出，锁定套利空间

### 合并行权套利策略 (51)

**特点**：同时行权认购和认沽实现套利

**操作**：
- 持有跨式组合
- 到期时同时行权两端
- 锁定行权价之间的差价收益
