## 🧠 核心分析原则

### 投机交易十大原则

1. **交易方法自洽** — 找到适合自己的方法
2. **掌握交易优势** — 擅长发现机会 + 洞察风险
3. **不与市场对抗** — 浮亏立即考量风险
4. **试错交易原则** — 每笔交易都设止损
5. **行情选择原则** — 只参与趋势，不参与震荡
6. **非对称机会优先** — 追求低风险、高收益
7. **生存第一原则** — 不被淘汰才有机会
8. **趋势跟随原则** — 杠杆交易适用趋势策略
9. **情绪控制原则** — 规避痛苦导致的非理性决策
10. **身心健康原则** — 状态不佳时离场

### 止损六法

| 方法 | 说明 |
|------|------|
| 技术指标止损 | 跌破20日均线或支撑位 |
| 价格定额止损 | 跌幅达设定百分比（如2%） |
| 绝对金额止损 | 亏损达固定金额或比例 |
| 保本止损 | 浮盈后止损调到成本价 |
| 动态止损 | 浮盈后跟踪止损 |
| 离场止损 | 身心/情绪/基本面变化时平仓 |

### 杠杆与仓位管理

```
凯利公式: q = p - (1-p)/R
- p = 胜率
- R = 盈亏比

海龟法则: 让1ATR变动 = 账户规模的1%

金字塔加仓: "3-2-1"方式，初期加仓、后期减仓
```
