## 📚 简介

`speculation-journey` 是为 Claude Code 设计的 Skill，整合了许星《投机苦旅》一书的完整内容，为交易者提供：

- **完整知识库**：5章书籍内容 + 术语表 + 金句库
- **决策辅助工具**：交易前检查、决策助手、错误自检
- **实时数据查询**：股票/ETF/期货/期权/宏观数据
- **交易框架**：十大原则、止损六法、仓位管理

**适用场景**：杠杆交易（外汇、商品、指数、期权）、投机交易、风险控制、交易心理

## 🧠 核心分析原则

### 投机交易十大原则

1. **交易方法自洽原则** — 找到适合自己的方法，而非盲目模仿大师
2. **掌握交易优势原则** — 必须掌握可重复利用的获利规律
3. **不与市场对抗原则** — 一旦市场通过浮亏告诉你你错了，必须立即考量风险
4. **试错交易原则** — 每笔交易都假设会错，主动设置止损是标准动作
5. **行情选择原则** — 只参与趋势行情，不参与震荡
6. **非对称机会优先原则** — 追求低风险、高收益的机会
7. **生存第一原则** — 不被市场淘汰，才有机会盈利
8. **趋势跟随原则** — 杠杆交易适用趋势跟随策略
9. **情绪控制原则** — 规避内心痛苦、寻求舒适感是非理性决策的根源
10. **身心健康原则** — 交易者身心健康是长期成功的基础

### 止损六法

| 方法 | 说明 | 适用场景 |
|------|------|----------|
| 技术指标止损 | 价格跌破20日均线或技术支撑位 | 趋势交易 |
| 价格定额止损 | 跌幅达设定百分比（如2%） | 日内交易 |
| 绝对金额止损 | 亏损达固定金额或账户比例 | 资金管理 |
| 保本止损 | 浮盈后迅速调整止损到成本价 | 保护利润 |
| 动态止损 | 浮盈后跟踪止损，如设为75%浮盈位 | 趋势跟踪 |
| 离场止损 | 身心健康/情绪/基本面重大变化时无条件平仓 | 风险控制 |

> "必须止损，错了也对。不设止损，如同开车不安装刹车系统。"

### 杠杆与仓位管理

**凯利公式**
```
q = p - (1-p)/R

p = 胜率
R = 盈亏比
```

**海龟法则**
```
以ATR确定仓位 — 让1ATR变动 = 账户规模的1%
```

**金字塔加仓**
```
"3-2-1"方式：初期加仓、后期减仓
```

**核心金句**
> "方向决定生死，仓位决定成败。"

## 📝 常见问题

### Q: 这个 Skill 适合所有人使用吗？

A: 本 Skill 主要针对**杠杆交易**者设计，包括外汇、期货、期权等。如果您从事股票等非杠杆交易，部分原则仍然适用，但需要调整。

### Q: 实时数据准确吗？

A: 数据来源于公开接口，可能有延迟或误差。**仅供参考，不构成投资建议**。正式交易请以券商数据为准。

### Q: 我需要安装 akshare 吗？

A: 不是必需的。不安装 akshare 仍可使用知识库和决策工具功能，但无法获取实时数据。
