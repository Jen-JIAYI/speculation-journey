# 第二章：新手的甜蜜时光

## Core Idea
作者初涉杠杆交易的辉煌战绩 —— 瑞郎事件、德指暴富、美糖战斗等，以及从中总结出的投机交易十大原则。

## Frameworks Introduced

### 投机交易十大原则

#### 原则一：交易方法自洽原则
- **核心**: 找到适合自己的方法
- **金句**: "每个人只会拥有自己真正领悟到的东西"
- **应用**: 不要盲目学巴菲特，价值投资需要强大的情绪管理能力

#### 原则二：掌握交易优势原则
- **核心**: 必须掌握可重复利用的获利规律
- **两类必要优势**:
  1. 擅于发现并抓住非对称性获利机会
  2. 擅于洞察风险避免巨大亏损
- **金句**: "行稳致远，学会能赚钱是一条支撑腿，学会不赔大钱是另一条支撑腿"

#### 原则三：不与市场对抗原则
- **核心**: 市场通过浮亏告诉你错了，必须立即考量风险
- **生存准则**: 避免大亏损 > 赚钱
- **警示**: 牛顿名言："我能算准天体的运行，却无法预测人类的疯狂"

#### 原则四：试错交易原则
- **核心**: 每笔交易都假设会错，主动设置止损
- **盈亏逻辑**: 赔多少靠人（止损），赚多少靠势（行情）
- **容错率**: 提高容错率的核心在于找准"支点"（趋势拐点）

#### 原则五：行情选择原则
- **核心**: 有所为有所不为，只参与趋势行情
- **慎战三原则**: 非利不动，非得不用，非危不战

#### 原则六至第十
- 生存第一、情绪控制、身心健康等原则

### 交易优势类型

| 优势类型 | 说明 |
|---------|------|
| 擅长区分好公司和坏公司 | 增加一份交易优势 |
| 擅长甄别低估值和高估值 | 再增加一份优势 |
| 擅长等待好时机和火候 | 又增加一份优势 |
| 擅长觉察坏苗头和坏信号 | 继续增加优势 |

## Key Concepts

- **自洽** — 交易方法与自身能力、性格相匹配
- **交易优势** — 可重复利用的获利规律
- **支点** — 多空变盘的转折点、行情拐点
- **试错交易** — 假设每笔都可能错，主动控制损失
- **慎战** — 慎重选择交易机会，不是所有行情都值得参与

## Mental Models

**狮群捕猎类比**（延续自第一章）:
- 幼狮从小观察学习 —— 投资者缺乏言传身教
- 成年狮专注最弱猎物 —— 交易需讲究胜率和盈亏比
- 成功率低但无胜算立即放弃 —— 高胜率容忍低盈亏比，低胜率必须高盈亏比
- 一旦受伤可能失去捕猎能力 —— 不要遭受重大亏损，唯有留在市场才有机会

**理想盈亏结构**:
```
10笔交易: 8笔各赔1元，2笔各赚5元 = 净赚2元
做错了少赔一点，做对了多赚一点
```

## Anti-patterns

- ***与市场对抗*** — "相信自己正确，是市场错了"会导致巨大损失
- ***过度自信*** — 来自信书本理论、研报、经验，但在杠杆中代价可能难以承受
- ***忽视止损*** — 试错交易原则下，主动设置止损是标准动作

## Key Takeaways

1. 交易方法必须自洽，适合自己的才是最好的
2. 必须掌握交易优势才能在市场中生存
3. 不与市场对抗是生存第一准则
4. 试错交易原则要求主动设置止损
5. 只参与趋势行情，震荡行情"有所不为"
6. "智者从别人的代价中吸取教训，愚者从自己的代价中吸取教训"
