# 第三章：爆仓！领教市场凶险

## Core Idea
作者的惨痛教训 —— 恒指牛爆证全军覆没、欧元交易致命错误、天然气交易、英国脱欧、钯金战役，以及从中领悟的止损六法。

## Frameworks Introduced

### 止损六法

1. **技术指标止损**
   - 上涨趋势中，价格跌破20日移动平均线即止损
   - 或下跌突破技术支撑位止损

2. **价格定额止损**
   - 开多单后，价格跌2%即止损
   - 设定固定的跌幅百分比

3. **绝对金额定额止损**
   - 亏损达到固定金额后止损
   - 或总账户市值、开仓金额的一定比例

4. **保本止损**
   - 开仓有浮盈后，迅速将止损线调整到开仓成本价
   - 确保本金安全

5. **动态止损**
   - 仓位有浮盈后，将止损价调整至75%浮盈的价格
   - 或设置价格点差，跟踪止损

6. **离场止损**
   - 发生身心健康、情绪控制、交易环境、资金性质、行情基本面等重大不利变化时
   - 无条件平仓离场

### 止损的核心认知

> "必须止损，错了也对。不设止损，如同开车不安装刹车系统。"

**关键认知**:
- 杠杆交易中，不设止损面临的爆仓风险是100%
- 不是会不会发生的问题，而是何时发生的问题
- 止损如同交强险，需要统一计算在交易成本之内

### 止损的挑战

- **艺术而非科学**: 止损设置极富挑战性
  - 过窄容易频繁触发
  - 过宽触及一次就是大损失
- **执行难于设定**: 市场常常出乎意料，被打止损是家常便饭

## Key Concepts

- **止损** — 限制单笔交易损失的风险控制手段
- **保本止损** — 浮盈后将止损调至成本价
- **动态止损** — 跟踪价格变动调整止损位
- **离场止损** — 基于非价格因素（身心健康、情绪等）的止损

## Mental Models

**救生圈类比**:
> 杠杆投机交易如同在太平洋里游泳，业余选手和专业运动员差别不大，但是否有救生圈差别很大。

**外科手术类比**（科斯托拉尼）:
> "最难的是在证券市场里承认赔钱，但就像外科手术，在病毒扩散之前，必须把手臂截肢，愈早愈好。"

**止损设置思考框架**:
> "如果我是对的，那么什么事情不应该发生？这个问题的答案就是停损点。"

## Anti-patterns

- ***不止损*** — "不设等死，设了找死"，但不设是100%爆仓
- ***过窄止损*** — 容易频繁触发，白白损失本金
- ***过宽止损*** — 触及一次就是大损失
- ***抱住亏损仓位*** — 因逃避痛苦而不闻不问，结果越亏越多
- ***过早平仓盈利*** — 因害怕失去浮盈而过早卖出

## Key Takeaways

1. 杠杆交易必须止损，错了也对
2. 不设止损面临100%爆仓风险
3. 止损设置是艺术，需要在实践中摸索
4. 止损的难点在执行而非设定
5. 学会直面痛苦、处理痛苦，才能成为成功交易者
6. 成功属于做到止损的人，失败属于做不到的人
