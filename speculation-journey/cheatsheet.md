# 投机苦旅 —— 快速参考

## 核心原则速查

### 投机交易十大原则

| # | 原则 | 核心要点 |
|---|------|----------|
| 1 | 交易方法自洽 | 找到适合自己的方法 |
| 2 | 掌握交易优势 | 必须有可重复利用的获利规律 |
| 3 | 不与市场对抗 | 浮亏时立即考量风险 |
| 4 | 试错交易 | 每笔都假设会错，主动止损 |
| 5 | 行情选择 | 只参与趋势，不参与震荡 |
| 6 | 非对称机会优先 | 追求低风险高收益 |
| 7 | 生存第一 | 留在市场里才有机会 |
| 8 | 趋势跟随 | 杠杆交易适用趋势策略 |
| 9 | 情绪控制 | 克服贪婪与恐惧 |
| 10 | 身心健康 | 异常时无条件平仓 |

## 止损决策树

```
有浮盈?
├─ 是 → 调整止损到成本价（保本）
│     └─ 继续浮盈 → 跟踪止损（75%浮盈位）
│
└─ 否 → 触及止损?
      ├─ 是 → 立即平仓
      └─ 否 → 身心/情绪/基本面异常?
            ├─ 是 → 立即平仓（离场止损）
            └─ 否 → 继续持有
```

## 策略选择决策

| 交易类型 | 推荐策略 | 理由 |
|----------|----------|------|
| 杠杆交易 | 趋势跟随 | 容错率低，波动是敌人 |
| 非杠杆长期 | 价值回归 | 有时间等待价值回归 |
| 危机时刻 | 危机阿尔法 | 恐慌产生持续趋势 |
| 日常交易 | 试错+止损 | 保护本金优先 |

|--------|------|---------|

## 常见错误警示

| 行为 | 后果 | 正确做法 |
|------|------|----------|
| 不设止损 | 100%爆仓 | 必须设止损 |
| 杠杆价值投资 | 容易爆仓 | 改用趋势跟随 |
| 过早止盈 | 错失大盈利 | 让利润奔跑 |
| 死扛亏损 | 越亏越多 | 迅速止损 |
| 频繁交易 | 手续费侵蚀 | 减少频率 |
| 逆势抄底 | 接飞刀 | 等待趋势确认 |

## 关键数字记忆

- **期货大赛**: 80%参与者亏损
- **盈利来源**: 80%盈利来自5单以内
- **交易频率**: 每日10次以上 → 3年收益率-80%
- **理想胜率**: <50%，但盈亏比>1
- **凯利公式**: q = p - (1-p)/R

## 危机信号识别

| 信号 | 含义 | 行动 |
|------|------|------|
| 月收益率 < -1σ | 市场危机 | 考虑危机阿尔法 |
| 流动性枯竭 | 恐慌抛售 | 谨慎开仓 |
| 跳空缺口 | 情绪极端 | 跟随趋势 |
| 连续涨跌停 | 趋势强化 | 不要逆势 |

## 心理健康检查

**交易前自问**:
1. 我是否因亏损而焦虑？
2. 我是否因盈利而过度兴奋？
3. 我是否在逃避查看账户？
4. 我是否有"扳回来"的想法？

**任何"是"** → 考虑离场止损
