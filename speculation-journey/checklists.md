# 交易前检查清单 —— 基于《投机苦旅》框架

> **使用说明**：每次开仓前，用这个清单逐项检查。任何一项不符合，建议不要交易。

---

## ✅ 核心检查（必做）

### 1. 非对称机会检查

| 检查项 | 你的答案 |
|--------|----------|
| 这笔交易是否风险有限、收益潜力大？ | ☐ 是 ☐ 否 |
| 风险收益比是否至少 1:2 或更好？ | ☐ 是 ☐ 否 |
| 如果我是对的，能赚多少？ | ___________ |
| 如果我是错的，会亏多少？ | ___________ |
| 我能承受这个最大亏损吗？ | ☐ 是 ☐ 否 |

**许星提醒**：
> "高风险 ≠ 高收益。我们追求的是低风险+高收益的非对称机会。"

如果答案是**否** → **不要交易**

---

### 2. 行情选择检查

| 检查项 | 你的答案 |
|--------|----------|
| 当前是明显的趋势行情吗？ | ☐ 是 ☐ 否 |
| 如果是，趋势方向是什么？ | ☐ 上涨 ☐ 下跌 ☐ 不确定 |
| 这是趋势的哪个阶段？ | ☐ 启动 ☐ 中途 ☐ 末期 |
| 当前是否处于震荡整理？ | ☐ 是 ☐ 否 |

**许星提醒**：
> "有所为有所不为。只参与趋势行情，不参与震荡。"

如果是**震荡行情** → **观望等待**

---

### 3. 止损设置检查

| 检查项 | 你的答案 |
|--------|----------|
| 我设置止损了吗？ | ☐ 是 ☐ 否 |
| 止损方式是什么？ | ___________ |
| 止损价位在哪里？ | ___________ |
| 止损金额占账户比例？ | ___________ |
| 止损金额占本笔交易比例？ | ___________ |

**许星提醒**：
> "必须止损，错了也对。不设止损，如同开车不安装刹车系统。"

如果**没设置止损** → **不要交易**

---

### 4. 仓位管理检查

| 检查项 | 你的答案 |
|--------|----------|
| 这笔交易是什么类型的仓位？ | ☐ 事实型 ☐ 欲望型 |
| 仓位大小是否合理？ | ☐ 是 ☐ 否 |
| 如果连续亏损3笔，能承受吗？ | ☐ 是 ☐ 否 |
| 单笔最大亏损是否<账户5%？ | ☐ 是 ☐ 否 |

**许星提醒**：
> "方向决定生死，仓位决定成败。"
> "赔钱的往往是欲望型仓位。"

如果是**欲望型仓位**或**仓位过大** → **减少仓位或不交易**

---

### 5. 交易优势检查

| 检查项 | 你的答案 |
|--------|----------|
| 我在这个品种上有交易优势吗？ | ☐ 是 ☐ 否 |
| 优势是什么？（技术/基本面/时机） | ___________ |
| 我有类似的盈利经验吗？ | ☐ 是 ☐ 否 |
| 这是我的"试错"还是有把握的交易？ | ___________ |

**许星提醒**：
> "必须掌握交易优势，才能在市场中生存。"
> "不掌握交易优势的人，进入市场就是赌运气。"

如果**没有明确优势** → **小仓位试错或不交易**

---

## 🔍 深度检查（强烈建议）

### 6. 情绪状态检查

| 检查项 | 你的答案 |
|--------|----------|
| 我现在身心状态良好吗？ | ☐ 是 ☐ 否 |
| 我是否因为之前的亏损而想"扳本"？ | ☐ 是 ☐ 否 |
| 我是否因为害怕错过而焦虑？ | ☐ 是 ☐ 否 |
| 我是否能冷静接受亏损的结果？ | ☐ 是 ☐ 否 |
| 我是否有其他事情影响交易决策？ | ☐ 是 ☐ 否 |

**许星提醒**：
> "规避内心痛苦、寻求舒适感是非理性决策的根源。"

如果有**任何情绪问题** → **离场止损（原则十）**

---

### 7. 市场环境检查

| 检查项 | 你的答案 |
|--------|----------|
| 最近是否有重大事件？（数据/政策/危机） | ☐ 是 ☐ 否 |
| 市场流动性是否正常？ | ☐ 是 ☐ 否 |
| 波动率是否异常？ | ☐ 是 ☐ 否 |
| 这是危机时刻吗？ | ☐ 是 ☐ 否 |

**许星提醒**：
> "市场危机不常有，务必重视每一次危机、珍惜每一次危机。"

如果是**危机时刻** → **考虑危机阿尔法策略或谨慎**

---

### 8. 策略一致性检查

| 检查项 | 你的答案 |
|--------|----------|
| 这笔交易符合我的交易系统吗？ | ☐ 是 ☐ 否 |
| 我是否偏离了通常的做法？ | ☐ 是 ☐ 否 |
| 我是否因为"感觉"而交易？ | ☐ 是 ☐ 否 |
| 这笔交易能写清楚理由吗？ | ☐ 是 ☐ 否 |

**许星提醒**：
> "每个人只会拥有自己真正领悟到的东西。"
> "交易方法必须自洽，适合自己的才是最好的。"

如果**不符合自己的系统** → **重新考虑**

---

## 🚫 最后的"否决权"检查

在点击"下单"之前，最后问自己一次：

| 问题 | 答案 |
|------|------|
| 如果这笔交易亏损100%，我能接受吗？ | ☐ 能 ☐ 不能 |
| 我是不是在"赌博"而不是"投机"？ | ☐ 是 ☐ 否 |
| 我是否违反了任何一条投机交易原则？ | ☐ 是 ☐ 否 |
| 我现在能否清晰地写下完整的交易计划？ | ☐ 能 ☐ 不能 |

**如果任何答案是否定的 → 不要交易！**
