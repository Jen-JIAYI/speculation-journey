# 决策助手 —— 许星的交易智慧

> **使用说明**：当你面临交易决策时，用这个框架来思考。找到你当前的问题，按指引行动。

---

## 🎯 开仓决策

### 问题：我现在应该开仓吗？

**第一步：检查非对称机会**
```
问自己：这是低风险、高收益的机会吗？
├─ 风险有限？（有明确止损）
├─ 收益潜力大？（盈亏比至少1:2）
└─ 胜率如何？（有确定逻辑）
```
- ✅ 都符合 → 继续
- ❌ 有不符合 → **观望**

**第二步：检查行情状态**
```
当前是趋势还是震荡？
├─ 明确趋势 → 可以考虑
└─ 震荡整理 → 坚决不参与（原则五）
```

**第三步：检查止损**
```
如果我是错的，会在哪里止损？
├─ 止损价位明确 → 继续
└─ 止损不明确 → **不交易**
```

**第四步：检查仓位**
```
如果错了，能承受这个损失吗？
├─ 最大亏损 < 账户5% → 可以
└─ 最大亏损 > 账户5% → **减少仓位**
```

## 🛑 止损决策

### 问题：我应该止损吗？

**已经触发止损价位？**
- ✅ 是 → **立即止损，不要犹豫**
- ❌ 否 → 继续检查

**是否离场止损的情况？**
```
检查以下任何一项：
├─ 身心状态异常（焦虑、失眠）
├─ 情绪失控（想"扳本"）
├─ 交易环境变化（无法正常交易）
├─ 资金性质变化（急用钱）
└─ 基本面重大变化（方向逆转）
```
- ✅ 有任何一项 → **立即平仓离场**

**许星会说**：
> "必须止损，错了也对。不设止损，如同开车不安装刹车系统。"

## 📈 加仓/减仓决策

### 问题：我应该加仓还是减仓？

**检查当前状态**
```
有浮盈吗？
├─ 是 → 考虑加仓，但要：
│   ├─ 用金字塔方式（3-2-1）
│   ├─ 不要等比例加仓（会抬高成本）
│   └─ 浮盈回撤时要警惕
└─ 否（浮亏） → **绝不加仓！**
```

**许星警告**：
> "浮盈加仓的方式很重要。如果是等比例加仓，很快会抬高你的建仓平均成本。"
> "浮亏加仓、或者死扛亏损单，要猛然惊醒！"

## 🔄 平仓决策

### 问题：我应该现在平仓吗？

**有浮盈，要不要平仓？**
```
问自己：
├─ 趋势还在吗？
│   ├─ 是 → 继续持有，让利润奔跑
│   └─ 否 → 平仓离场
├─ 是否因为害怕失去浮盈而想平仓？
│   ├─ 是 → 克服恐惧，不要过早止盈
│   └─ 否 → 可以平仓
└─ 是否已经达到止盈目标？
    ├─ 是 → 可以部分平仓锁定利润
    └─ 否 → 继续持有
```

**有浮亏，要不要平仓？**
```
问自己：
├─ 是否已触及止损？
│   ├─ 是 → **立即平仓**
│   └─ 否 → 继续持有
├─ 是否因为"不想认错"而持有？
│   ├─ 是 → **这是危险信号，立即平仓**
│   └─ 否 → 可以继续
└─ 市场是否已经证明我错了？
    ├─ 是 → **立即平仓，不要与市场对抗**
    └─ 否 → 继续持有
```

**许星会说**：
> "对浮盈的仓位心怀恐惧，因害怕浮盈消失而过早卖出。"
> "对亏损的仓位却满怀希望，交易者下意识避免打开账户。"

## 💡 遇到问题时

### 问题：我被套了，怎么办？

**立即检查清单**
```
1. 设置止损了吗？
   ├─ 没有 → **立即设置，或者立即平仓**
   └─ 有了 → 继续

2. 亏损有多大？
   ├─ < 账户5% → 可以继续观察
   ├─ 5%-10% → 警惕，考虑减仓
   └─ > 10% → **应该已经止损了！**

3. 是为什么而持有？
   ├─ 有明确的交易理由 → 检查理由是否还成立
   └─ 只是"不想认赔" → **立即平仓**

4. 市场在告诉我什么？
   ├─ 浮亏在扩大 → 市场在说你错了
   └─ 浮亏在减少 → 可能有机会
```

**许星警告**：
> "与市场对抗，代价可能会大到难以想象、难以承受。"
> "赔大钱的根源在于不肯尽早退出亏损的头寸。"

## 🎲 判断机会

### 问题：现在有行情吗？

**判断框架**
```
1. 是趋势还是震荡？
   ├─ 明确趋势 → 有行情
   └─ 震荡整理 → 没行情，观望

2. 趋势处于什么阶段？
   ├─ 启动阶段 → 最佳入场点
   ├─ 中途阶段 → 可以跟随，但谨慎
   └─ 末期阶段 → 风险大，观望

3. 是否是危机时刻？
   ├─ 是 → 危机阿尔法机会
   └─ 否 → 正常判断
```

**许星提醒**：
> "市场危机不常有，投机客务必重视每一次危机、珍惜每一次危机。"
> "非利不动，非得不用，非危不战。"

## 🧠 自我拷问（关键时刻）

### 在任何决策前，问自己：

**许星的五大拷问**
```
1. 这是事实型交易还是欲望型交易？
   └─ 如果是欲望型 → 不要交易

2. 如果我是对的，什么事情不应该发生？
   └─ 这个问题的答案就是止损点

3. 我是在找非对称机会，还是在赌博？
   └─ 如果是赌博 → 立即停止

4. 这笔交易符合哪条（些）投机交易原则？
   └─ 如果违反任何原则 → 重新考虑

5. 我能承受最坏的结果吗？
   └─ 如果不能 → 不要交易
```
