# 投机苦旅 —— 交易模式与方法

## 趋势跟随策略

**何时使用**: 杠杆交易、无法预测市场、承认可能犯错

**如何实施**:
1. 不预测市场公允价值
2. 按照市场趋势信号做交易
3. 设置止损控制风险
4. 跟踪止盈让利润奔跑
5. 接受较低的胜率，追求高盈亏比

**收益特征**: 正偏度（右尾肥大），胜率<50%，盈亏比>1

**适用场景**: 外汇、期货、股指等杠杆交易市场

---

## 价值回归策略

**何时使用**: 非杠杆交易、有能力持有较长时间、确信价值判断

**如何实施**:
1. 判断标的内在价值
2. 低估时做多，高估时做空
3. 亏损时可能加仓
4. 相信长期价值回归

**收益特征**: 负偏度（左尾肥大），胜率较高但有少数大亏损

**适用场景**: 股票长期投资、非杠杆市场

**⚠️ 杠杆交易慎用**: 容错率低，容易爆仓

---

## 危机阿尔法策略

**何时使用**: 市场出现危机（月度收益率低于一个标准差以上）

**如何实施**:
1. 屏蔽多头偏差、本土偏差、羊群效应
2. 允许做空
3. 识别危机引发的持续性趋势
4. 顺势跟随
5. 严格止损防止黑天鹅反转

**运作机制**:
```
危机 → 恐慌抛售 → 流动性枯竭 → 连锁反应 → 持续趋势
```

**典型机会**:
- 2020新冠暴跌
- 2020负油价
- 2022俄乌冲突
- 极度恐慌的市场底部

---

## 随机入市交易系统

**何时使用**: 有一定经验的小散，避免主观臆测

**如何实施**:
1. 根据市场信号按"事实"开多单或空单
2. 严格遵循系统步骤
3. 设置止损控制损失
4. 跟踪止盈设置
5. 让浮盈自我成长

**优势**: 避免抄底摸顶的主观判断

---

## 止损六法

### 1. 技术指标止损
- **方法**: 价格跌破20日均线或技术支撑位
- **适用**: 有明确技术参照的交易

### 2. 价格定额止损
- **方法**: 跌幅达设定百分比（如2%）
- **适用**: 波动相对稳定的品种

### 3. 绝对金额止损
- **方法**: 亏损达固定金额或账户比例
- **适用**: 资金管理严格的交易者

### 4. 保本止损
- **方法**: 浮盈后迅速调整止损到成本价
- **适用**: 已有浮盈的头寸

### 5. 动态止损
- **方法**: 浮盈后跟踪止损，如设为75%浮盈位
- **适用**: 趋势性较强的行情

### 6. 离场止损
- **方法**: 身心健康/情绪/基本面重大变化时无条件平仓
- **适用**: 所有交易，最后的保护防线

## 金字塔加仓法（3-2-1）

**何时使用**: 浮盈确认趋势正确后

**如何实施**:
```
初期（山脚）: 3份仓位确认入场
中期（山腰）: 2份仓位跟随加仓
后期（山顶）: 1份仓位谨慎参与
```

**注意事项**:
- 避免等比例加仓（会抬高平均成本）
- 浮盈回撤时要警惕趋势反转
- 只在趋势确认时加仓，亏损时绝不加仓

---

## ATR仓位管理法

**何时使用**: 需要根据波动率调整仓位

**公式**: 让1ATR的价格变动 = 账户规模的1%

**示例**:
```
账户: 10万美元
允许1ATR变动: 1000美元（1%）

标普500报价5000点，每点1美元
标普500 ATR: 50点
1手合约1ATR变动 = 50美元

合约数量 = 1000 / 50 = 20手
```

**逻辑**: 波动率大的品种仓位更小

---

## 凯利公式仓位计算

**公式**: q = p - (1-p)/R
- q = 合理仓位比例
- p = 胜率
- R = 盈亏比

**示例**:
```
胜率p = 49.52%
盈亏比R = 1.9

q = 0.4952 - (1-0.4952)/1.9 = 0.23
合理仓位约23%
```

## 支点交易策略

**核心**: 找准多空变盘的转折点、趋势启动点

**价值**:
- 提高容错率
- 降低仓位过大风险
- 增加交易确定性

**方法**:
- 等待明确趋势信号
- 结合基本面和技术面共振
- 设置较窄的止损（因为认为在拐点）

---

## "进二退一"节奏策略

**核心**: 让账户净值螺旋式上升

**要求**:
- "进二" — 赚的时候多赚
- "退一" — 赔的时候少赔

**实现**:
- 严格止损控制"退"的幅度
- 不轻易止盈让"进"充分发展
- 趋势中敢于加仓扩大盈利

---

## 非对称机会识别

**特征**:
1. 风险有限（有明确止损位）
2. 收益空间大（盈亏比高）
3. 胜率较高（有确定逻辑支撑）
4. 赔率高（潜在回报大）

**常见场景**:
- 极度恐慌后的反弹
- 基本面反转前夕
- 技术面突破后回踩确认
- 事件驱动的确定性趋势

---

## 情绪控制模式

**盈利时**:
- 克服"失去浮盈的恐惧"
- 不要过早平仓
- 让利润奔跑

**亏损时**:
- 克服"逃避痛苦的本能"
- 不要死扛亏损
- 迅速止损

**核心**: 做一个不受情绪支配的人
